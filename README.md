# «Можно» · учебный прототип

Основа из шаблона курса: https://github.com/arzghost/technical_literacy. На / открываются «Счета» с семью учебными кармашками. Нажатие на карточку открывает её детали. На /design-system находятся образцы перенесённой части ДС. Данные не сохраняются в базе, настоящие счета, авторизация и LLM пока не подключены. Для запуска ключи не нужны.

## Первые пять минут
Нужны Node 24.x, npm и Git. Склонируйте https://github.com/madebyvlada/technical-literacy.git, перейдите в папку репозитория:

```text
git clone https://github.com/madebyvlada/technical-literacy.git
cd technical-literacy
npm ci
npm run dev
```

Откройте адрес из терминала (обычно http://localhost:3000). PowerShell: при блокировке npm.ps1 используйте npm.cmd. Для Git откройте второй терминал. Главная страница называется «Счета». Влада выполнила учебную правку суммы и вернула исходное значение; рабочий пример остаётся в lib/demo-pockets.ts.

## Проверки
```text
npm run typecheck
npm test
npm run build
npx playwright install chromium
npm run test:e2e
```

CI запускает эти же проверки на push/PR. E2E поднимает свой сервер на 3100. Перед запуском остановите npm run dev этого проекта через Ctrl+C: Next не допускает два dev-процесса для одной папки. После тестов снова запустите npm run dev. Smoke-тест — пример инструмента, не закрывает будущий сценарий КТ-4.

## Карта
- app/page.tsx — Счета и список данных; lib/demo-pockets.ts — учебные кармашки; components/pocket-card.tsx — их общий компонент.
- app/api/health/route.ts — серверный маршрут для Network.

- components/course-card.tsx — компонент с props для МЗ-2, не button.tsx.
- components/ui/button.tsx — локальная адаптация shadcn/ui на Radix с asChild.
- app/globals.css — токены Tailwind 4 через @theme.
- PRODUCT.md — рабочее описание продукта с открытым вопросом ролей; AGENTS.md — правила агента и исходные инструкции Next.js; DESIGN.md — перенесённое оформление; DECISIONS.md — журнал фактических решений.
- tests/unit и tests/e2e, .github/workflows/ci.yml — работающие примеры проверок.
- docs и supabase/migrations — заготовки следующей работы.

Не коммитить реальные .env, ключи и тестовые пароли. .env.example содержит только имена. Публикация репозитория на GitHub не заменяет деплой на Vercel. Баллы и сроки — по выданному силлабусу.

## КТ-2 · как проверить состояния

Откройте адрес со страницы локального запуска. Параметр state показывает учебный пример. «Повторить» возвращает обычный экран.

| Что видно | Счета | Кармашек «Аренда» |
|---|---|---|
| Данные | `/` | `/pockets/rent` |
| Загрузка | `/?state=loading` | `/pockets/rent?state=loading` |
| Пусто / отсутствует | `/?state=empty` | `/pockets/rent?state=empty` |
| Ошибка и повтор | `/?state=error` | `/pockets/rent?state=error` |

Проверьте две страницы карточек на «Счетах», переход в «Аренду» и назад. Для неизвестного идентификатора также показывается «Кармашек не найден». Пополнение, переводы и настройки в этой версии недоступны.
