## Предупреждение зависимостей

npm audit сообщает пять high-записей: picomatch и цепочка fdir/tinyglobby/vite/vitest. Это одна исходная advisory GHSA-fc5q-39xc-vjpf и затронутые зависимости, а не пять независимо подтверждённых уязвимостей приложения. `npm ls picomatch --all` показал picomatch4.0.7 в цепочке Vitest4.1.12. [Официальная advisory](https://github.com/advisories/GHSA-fc5q-39xc-vjpf) указывает риск зависания при специально составленных шаблонах поиска; на момент проверки исправленная версия не указана.

Пакеты и lock не менялись. Автоматическое npm audit fix --force не выполнялось: оно предлагает смену основной версии Vitest. В текущем экране пользовательские шаблоны поиска не принимаются. Это ограничивает доступный путь к проблеме, но не является исправлением. Следующее действие по предупреждению: проверить появление исправленного picomatch перед обновлением инструментов, затем отдельно согласовать изменение пакетов и прогнать проверки.

Сдача ссылкой в чат курса и принятие преподавателем этим отчётом не подтверждаются. Вторая роль относится к следующему объёму продукта, вопрос уже отправлен18.11.
