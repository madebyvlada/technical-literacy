# Исправление высоты кармашков · 18 ноября 2026

## Задача

Влада обнаружила при ширине 360px: подпись «Аренды» занимает две строки, и её карточка выше остальных. Нужно сделать все четыре карточки блока одинаковой высоты, сохранив весь текст. Данные, токены и внешний вид карточки сохраняются.

## Принятый план

Влада приняла план сообщением «газ» после объяснения причины и списка проверок.

1. В app/globals.css строки сетки блока получают одинаковую высоту по содержимому самой высокой карточки; элементы списка и карточки растягиваются на неё.
2. Не фиксировать высоту числом, не обрезать и не сокращать подписи.
3. Добавить проверку фактической высоты поверхностей карточек и размещения текста при 320/360/393px в tests/e2e/pocket-layout.spec.ts. Сначала показать провал при 360 на прежнем CSS.
4. Запустить существующие проверки, визуально посмотреть результат и записать факты в docs/bugs.md, DESIGN.md и DECISIONS.md.

Ручные изменения Влады «Мои счета» и соответствующее ожидание старого теста сохраняются. next-env.d.ts автоматически изменён dev-сервером; не включать его без разбора как часть исправления. Коммит и отправка в этой задаче не выполняются без отдельного поручения.

## Результат

Новый тест при 360px на прежнем CSS действительно упал: ожидалась разница высоты меньше 1px, получено 18px. Исходный отчёт и trace сохранены локально в родительской папке tmp/pocket-height-before-fix; это фактический прогон, не имитация провала.

Исправлено только правило блока: grid-auto-rows:1fr, align-items:stretch и display:grid у li. Это позволяет поверхностям карточек занять одинаковую высоту строк сетки, сохраняя естественное размещение текста.

После исправления все 6 Chromium e2e прошли: три новые ширины и три прежние проверки. Typecheck и git diff --check успешны. Использована существующая временная .next/revert-playwright.config.ts на работающем сервере 3000; штатная конфигурация не менялась. Отдельная production-сборка в этой задаче не запускалась.

В браузере дополнительно визуально проверен 360px: каждая поверхность 156×124px, подпись Аренды полностью видна на двух строках.
